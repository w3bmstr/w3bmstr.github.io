Software

SpreadsheetSaga

Problem
Teams needed a serious spreadsheet workspace without uploading sensitive data to a cloud suite.
Approach
Built a local-first grid with formulas, CSV import/export, and session persistence — all on-device, no backend.
Result
A production spreadsheet tool that opens instantly, keeps data private, and works offline by design.

Audio

Groove Player

Problem
Most browser players are thin wrappers — no real EQ, queue control, or local file workflow for MP3/MP4.
Approach
Designed a local music player with equalizer, queue, and DSP tools that never leaves the user’s machine.
Result
A focused listening tool with studio-leaning controls and zero upload friction — open a file and play.

Gallery

Photography Gallery

Problem

Approach
Built an image-first gallery with optional fine-art style presets, quiet typography, and editorial spacing that keeps the work in front.
Result
A calm, production-ready photography system — original work, optional looks, and a layout that stays out of the way.

Finance

LedgerOS

Problem
Small teams need real bookkeeping — invoices, payroll, reports — without locking data into a SaaS they can’t audit offline.
Approach
Designed a full local ledger suite with double-entry logic, invoices, payroll, and reports that never leave the device.
Result
A complete bookkeeping OS in the browser — private by default, offline-capable, and structured for real operations.

Documents

MyPDF

Problem
Annotating, signing, or marking up a PDF usually means uploading a private document — a contract, an ID, a form — to someone else's server first.
Approach
Built a fully local PDF viewer with an ink and annotation layer, signature capture, and a built-in scanner, so the file never leaves the device.
Result
A private, fast PDF workspace — open, mark up, sign, and export, with nothing ever touching a server.
Open live demo →
Scanning

ScanMagic

Problem
Turning paper into a searchable PDF usually means a scanning app that quietly uploads every photo you take.
Approach
Built an on-device scanner with edge detection, cleanup filters, and OCR that runs entirely in the browser, exporting straight to a multi-page PDF.
Result
A pocket scanner that turns real paper into searchable, exportable PDFs — without a single image leaving the device.
Open live demo →
Calculator

Lumina Calculator

Problem
Students and professionals juggle three or four separate calculator apps for scientific work, graphing, and financial math.
Approach
Built one precision calculator covering scientific functions, function graphing, financial formulas, and unit conversion in a single interface.
Result
A single calculator that replaces the drawer of apps — accurate, fast, and fully usable offline.
